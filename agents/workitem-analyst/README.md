# Workitem Analyst

Delivery Squad 的分析角色，负责需求与纠正性问题的工程分析、OpenSpec Change 准备及人工审核提交。专业边界见 [Instructions](instructions.md)，设计背景见 [03 Workitem Analysis](../../03-workitem-analysis-design.md)。

角色资产：[Instructions](instructions.md) · [Description](description.md)。

- [codebase-explorer](../../skills/codebase-explorer/SKILL.md)：工程探索。
- [bug-analysis](../../skills/bug-analysis/SKILL.md)：Corrective 根因分析。
- [requirement-analysis](../../skills/requirement-analysis/SKILL.md)：Intentional 需求分析。
- [spec-preparation](../../skills/spec-preparation/SKILL.md)：OpenSpec 工件准备。
- [analysis-completion](../../skills/analysis-completion/SKILL.md)：分析结果提交与状态确认。
- [workspace-preparation](../../skills/workspace-preparation/SKILL.md)：需要本地根仓时准备工作区。
