# Frontend Engineer 配置资产

Delivery Squad 的专业实现成员。长期职责以 [Instructions](instructions.md) 为准；展示文案见 [Description](description.md)。

## 执行方法

- [development-execution](../../workspace-skills/development-execution/SKILL.md)：共同的研发、验证、Commit / Push、PR Preparation 与 Evidence 方法。
- [frontend-engineering](../../workspace-skills/frontend-engineering/SKILL.md)：领域反馈信号、验证与工程审查标准。
- [pull-request](../../workspace-skills/pull-request/SKILL.md)：PR 物化契约。

Agent 的 Skill 绑定和 Squad 成员配置唯一来源为 [provisioning.json](../../workspace-skills/_shared/provisioning.json)；本页不维护复制的绑定 ID 或历史 Runtime 快照。

平台对象通过 `rondo workspace provision --workspace <name>` 发布与回读；Skill 内容通过 `rondo workspace sync --workspace <name>` 同步。
