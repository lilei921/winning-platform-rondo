# OpenSpec 工程任务写法

## 1. 工程 Task

一个任务描述一个可交付的工程结果和判断完成的方式。相关改动可放在同一项，例如一起移除两个未使用的依赖并验证构建。任务粒度取决于实际依赖和可验证结果，不因 TFS 任务数量、6h 上限调整，也不强制填写工时预估。

## 2. 验证方式选择

选择能证明结果的验证方式，例如已有测试、构建或可观察的行为。几个任务组合后才看得出的结果，可以单列一项集成验证。行为确实依赖浏览器或完整链路，或已批准的验收条件明确要求时，需安排相应的端到端验证。

`tasks.md` 中的 checkbox 用于 PR 前要完成的工程工作。人工验收或 PR 后独立验证的建议可以单独说明。
